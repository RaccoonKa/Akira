> [!TIP]
> **Seamless Auto-Updates &amp; Data Safety:** Akira checks GitHub Releases automatically, supports **split `.part01`, `.part02` release assets** (>2 GB workaround), and preserves all configs, memories, and SQLite Studio chats in `%APPDATA%\Akira` (Windows) or `~/.local/share/Akira` (Linux).

<details open>
<summary><b>🪟 Windows Installation (<code>.msi</code>)</b></summary>

1. Download `Akira-Setup-v5.1.0.msi` from [**GitHub Releases**](https://github.com/RaccoonKa/Akira/releases).
   - *If the release uses split parts (`.msi.part01`, `.msi.part02`, ...), download all parts into one folder, open `cmd` there, and merge them:*
     ```bat
     copy /b Akira-Setup-v5.1.0.msi.part* Akira-Setup-v5.1.0.msi
     ```
2. Run the `.msi` installer and follow the setup wizard.

</details>

<details open>
<summary><b>🐧 Linux Mint / Ubuntu / Debian Installation (<code>.deb</code>)</b></summary>

1. Download all `.deb.part*` files (`akira_5.1.0_amd64.deb.part01`, `akira_5.1.0_amd64.deb.part02`, ...) from [**GitHub Releases**](https://github.com/RaccoonKa/Akira/releases) into one folder.
2. Open a terminal in that folder, merge the parts, and install:
   ```bash
   cat akira_5.1.0_amd64.deb.part* > akira_5.1.0_amd64.deb && sudo apt install -y ./akira_5.1.0_amd64.deb
   ```
3. To uninstall later (keeps your configs in `~/.local/share/Akira`):
   ```bash
   sudo apt remove -y akira
   ```

</details>

<details>
<summary><b>🛠️ Build from Source (Nuitka)</b></summary>

```bash
# Windows
.venv\Scripts\python.exe build_nuitka.py

# Linux Mint / Ubuntu (builds .deb + .tar.gz and auto-splits >1.81 GiB assets for GitHub Releases)
.venv/bin/python build_nuitka.py --platform linux --format deb
```

</details>
